4 ferramentas que eu uso pra construir tudo com IA

Eu construo apps, sites e vídeos conversando com o Claude. Estas são as quatro ferramentas que mais aparecem no meu dia a dia, do 4º ao 1º. A nº 1 foi a que me criou.

Seu brinde: as 4 ferramentas, com o link oficial

4º · humanizer

Tira o jeito de texto de robô do que o Claude escreve. Use no fim, com o texto já pronto.

Link oficial: github.com/blader/humanizer
Para começar: npx skills add blader/humanizer

3º · caveman

Faz o Claude responder curto, sem enrolação, e usar menos texto de resposta. Os autores falam em economia grande de texto; esse número é do projeto e não foi medido por mim. Para voltar ao normal, é só pedir "normal mode".

Link oficial: github.com/JuliusBrussee/caveman
Para começar: siga a instalação do README do projeto.

2º · hyperframes

Você pede e o Claude monta o vídeo em código, sem abrir editor. Comece com um vídeo curto, de uns 10 segundos, só com texto.

Link oficial: github.com/heygen-com/hyperframes
Para começar: npx skills add heygen-com/hyperframes

1º · o navegador (Playwright MCP)

O Claude abre o navegador sozinho, clica, digita e faz a tarefa por você. Foi assim que o mascote do meu perfil nasceu. Comece com uma tarefa simples: "abra tal site e me diga o título".

Link oficial: github.com/microsoft/playwright-mcp
Para começar: siga a instalação do README (há um comando pronto para o Claude Code).

Quer o passo a passo completo? Como eu encadeio essas ferramentas para fazer um vídeo do roteiro ao arquivo final é o que vai na mentoria.
